# Spec

## 概要

本ディレクトリでは、GATES が満たす要求と、GATES が従う外部仕様の制約を管理します。

## ドキュメント一覧

| ファイル | 内容 |
|---|---|
| [Requirements](requirements.md) | GATES の目的、対象範囲、現在実現すべき要求と受け入れ条件 |
| [Future Scope](future-scope.md) | 現在のスコープと、将来取り込むことを想定している機能 |
| [GitHub Constraints](github-constraints.md) | GitHub Actions、GitHub App、GitHub REST API の仕様を、公式資料と調査記録を根拠に整理したもの |
| [JWT Constraints](jwt-constraints.md) | JWT / JWS / JWK / OpenID Connect の標準仕様から、署名・鍵・Claims・Discovery の検証に関係する規定を整理したもの |
